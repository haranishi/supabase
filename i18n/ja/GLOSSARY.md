# 用語集（暫定）

最初の数本を訳しながら見直す暫定版。訳語を変えるときは、既存の訳の置き換えも同じコミットに含める。

## 訳さない語

製品名、機能名、略語は英語のまま書く。

- 製品名と機能名: Supabase、Postgres、Studio、Auth、Storage、Realtime、Edge Functions、Supavisor、Webhook
- 略語: JWT、API、SQL、CLI、SDK、URL

Auth や Storage を製品名ではなく一般名詞として使う文では、下の「訳す語」の authentication（認証）や storage（ストレージ）に従う。

## 訳す語

- project: プロジェクト
- organization: 組織
- dashboard: ダッシュボード
- database: データベース
- schema: スキーマ
- table: テーブル
- row: 行
- column: 列
- migration: マイグレーション
- extension: 拡張機能
- branch: ブランチ
- connection pooling: コネクションプーリング
- Row Level Security: 行レベルセキュリティ。初出は「行レベルセキュリティ（Row Level Security、RLS）」と書き、以降は RLS と略す
- policy: ポリシー
- authentication: 認証
- authorization: 認可
- session: セッション
- API key: API キー
- storage: ストレージ
- bucket: バケット
- embedding: 埋め込み。初出は「埋め込み（embedding）」と書く
- vector: ベクトル
- queue: キュー
- logs: ログ
- observability: オブザーバビリティ
- self-hosting: セルフホスティング
- local development: ローカル開発
- quickstart: クイックスタート
- troubleshooting: トラブルシューティング
